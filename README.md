# Learn SecByte Cereal & Vengeance TFTP Linux CTF Labs

A curated collection of **hands-on cybersecurity labs and CTF challenges** focused on Cereal deserialization, Vengeance-themed challenges, Linux enumeration, Bash scripting, TFTP, process discovery, user trails, and network/channel security.

These labs are useful for **cybersecurity students, CTF players, pentesters, SOC analysts, and security learners** practicing security concepts in authorized environments.

## Introduction

This repository organizes Learn SecByte challenges around the **Cereal** and **Vengeance** lab themes. Topics include PHP deserialization, Linux enumeration, Bash scripting, TFTP security, process discovery, user-focused investigation, shell concepts, and network channels.

The repository is intended as a searchable learning index and does not contain leaked flags, credentials, or unauthorized access instructions.
